ACHILLES TRACKSUIT CREATOR

1. Upload BOTH index.html and tracksuit.glb to the same folder on your web host.
2. Open the hosted index.html URL (for example, your GitHub Pages or Vercel URL).
3. Do not double-click index.html from a downloaded folder: browsers block local 3D model loading for security.
4. To embed in Shopify, add the hosted page URL in an iframe, the same way as the current kit creator.

The page needs an internet connection because Three.js loads from a trusted CDN.
